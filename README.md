# 💴 JPY to RUB Currency Converter

A stylish, lightweight Python desktop application that converts Japanese Yen to Russian Rubles in real-time. 

## 🚀 Features
* **Live Data:** Fetches the actual exchange rate from the Central Bank of Russia API.
* **Modern UI:** Dark theme, flat buttons, and a clean interface built with `Tkinter`.
* **Anime Vibe:** Custom Yui Hirasawa `.ico` and Rei Ayanami aesthetics. 

## 🛠️ Tech Stack
* Python 3
* `tkinter` (GUI)
* `requests` (API)
